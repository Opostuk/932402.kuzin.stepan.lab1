# Лабораторная работа №1. Основы HTML и структура веб-страницы

**Автор:** Кузин Степан
**Тема (вариант 11):** Фотограф и визуальный сторителлер

## Описание

Одностраничный сайт «О себе» с базовыми семантическими тегами HTML5:
`header`, `main`, две `section` («Навыки» и «Проекты»), `aside`
(любимое направление — стрит-фото), `footer`, изображение с атрибутами
`src`, `alt`, `width`, `height`, а также форма обратной связи (Имя,
Email, Сообщение) с атрибутами `name` и `placeholder` у всех полей.

Цветовая гамма — серо-синяя, нейтральная, чтобы не отвлекать от фото.

## Файлы

- `lab1web.html` — страница (картинка встроена внутрь файла в base64)

## Как открыть

Открыть `lab1web.html` в браузере.
